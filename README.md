# artists field

Общий список художников. У каждого свой сайт-портфолио с облаком тегов, плитками работ и свободными холстами, на которых блоки лежат внахлёст. Всё редактируется прямо в браузере и сохраняется в этот репозиторий.

Живёт на GitHub Pages, сервер не нужен.

## Как устроено

```
index.html          главная: список художников
artists.json        данные списка (название, текст, художники)
app/                общий код: стили, сайт художника, редактор, сохранение в GitHub
  artist-page.html  шаблон страницы нового художника
  config.js         адрес репо, если сайт живёт на своём домене
a/<папка>/          сайт одного художника
  index.html
  data/works.json   его работы, теги, блоки
  img/              картинки, гифки, видео
```

## Запуск (один раз)

1. Залей этот репозиторий на GitHub (например, `artists-field`).
2. **Settings → Pages → Build and deployment:** Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<твой-логин>.github.io/artists-field/`.

## Как редактировать

1. Открой свой сайт и нажми **edit** внизу слева.
2. В первый раз сайт попросит токен GitHub:
   - [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new)
   - *Repository access* → *Only select repositories* → этот репо
   - *Repository permissions* → **Contents: Read and write**
   - Вставь токен. Он хранится только в этом браузере.
3. Правь: таблица работ (показать или скрыть, порядок, удалить), блоки на холсте, обложки, теги.
4. Нажми **save**. Получится один коммит, а публичный сайт обновится примерно через минуту.

## Как добавить коллегу

1. **Settings → Collaborators → Add people** → его логин на GitHub.
2. На главной нажми **edit list** → *add an artist* (имя и название папки) → появится `a/<папка>/` с пустым сайтом.
3. Отправь коллеге ссылку на его страницу. Он делает свой токен (шаги выше) и заполняет сайт сам.

Любой участник с доступом на запись технически может править любую папку. Договоритесь, что каждый трогает только свою; вся история изменений видна в коммитах.

## Ограничения

- **Размер файла:** до ~45 МБ, а лучше меньше. Большие видео сжимай заранее.
- **Обновление:** публичный сайт обновляется через ~1 минуту после save (сборка Pages).
- **Одновременная правка:** если двое сохраняют один и тот же сайт одновременно, побеждает последний.
